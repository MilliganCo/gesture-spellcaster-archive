# Gesture Spellcaster

Игра на Python с распознаванием жестов через $1 Recognizer. Отбивайтесь от волн врагов, рисуя руны мышью!

## Установка

1. Убедитесь, что у вас установлен Python 3.11 или выше:
```bash
python --version
```

2. Создайте виртуальное окружение (рекомендуется):
```bash
python -m venv venv
```

3. Активируйте виртуальное окружение:
   - Windows: `venv\Scripts\activate`
   - Linux/Mac: `source venv/bin/activate`

4. Установите зависимости:
```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

## Управление

- **ЛКМ (зажать)**: Начать рисование руны
- **ЛКМ (отпустить)**: Завершить руну и применить заклинание
- **ПКМ**: Отменить текущий жест
- **Space**: Принудительно завершить комбо-цепочку
- **R**: Перезапустить игру (после Game Over)

## Руны и заклинания

- **CROSS** (крест) → **Cross Shot**: Стреляет 4 снарядами во все стороны
- **CIRCLE** (круг) → **Nova**: AoE урон вокруг игрока
- **V** → **Cone**: Урон в конусе перед игроком
- **Z** → **Chain**: Цепная молния
- **S** → **Slow**: Замедление врагов
- **SPIRAL** (спираль) → **Drain**: Урон + лечение игрока

**Подсказка**: Справа на экране отображаются визуальные подсказки по всем рунам с их эффектами!

## Комбо-система

Рисуйте руны последовательно в течение 1.5 секунды, чтобы создать комбо-цепочку. Комбо отображается в HUD.

## Добавление новой руны

1. Откройте `assets/runes.json`
2. Добавьте новую руну с несколькими примерами жестов:
```json
"NEW_RUNE": [
  [[x1, y1], [x2, y2], ...],
  [[x1, y1], [x2, y2], ...]
]
```
3. Откройте `game/spells.py` и добавьте обработку в функцию `cast_spell()`:
```python
elif rune == "NEW_RUNE":
    # Ваш код эффекта
```

## Технические детали

- Использует алгоритм $1 Recognizer для распознавания жестов
- Rotation-invariant matching (поиск лучшего угла в диапазоне ±45°)
- Нормализация: resample до 64 точек, масштабирование, поворот
- Порог уверенности: 0.75 (жесты с меньшим score не распознаются)
